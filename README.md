# Beauty PWA

Luxury K-Beauty Routine Planner built with Next.js for Vercel deployment.

## Features
- AM / PM / Weekly routine planner
- Editable recommendations
- Smart recommendation engine based on skin profile
- JSON export / import
- Installable PWA
- Offline-ready service worker

## Stack
- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Vercel

## Local development
```bash
npm install
npm run dev
```

## Deploy
Import the repository into Vercel and deploy as a Next.js app.
